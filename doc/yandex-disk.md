# Инструкция по установке и настройке десктопного клиента Яндекс Диск

***

**Клиент по умолчанию не имеет графической оболочки! Его настройка производится средствами CLI (Command Line Interface, интерфейс командной строки)**

***

## Установка клиента

- Скачать с портала установочный пакет из Библиотеки приложений: [yandex-disk.deb](https://easyastra.ru/store1.8/yandex-disk.deb)
- Двойным кликом ЛКМ выполнить установку пакета средствами qApt

## Первичная настройка клиента

- Запустить терминал Fly: `Alt+T`
- Выполнить комманду: `yandex-disk setup`
- Последовательно ответить на предлагаемые вопросы:
  - `Использовать прокси-сервер? [y/N]:`
  - Перейти на [страницу авторизации](https://ya.ru/device) в браузере
  - Выполнить авторизацию аккаунта по адресу почты или номеру телефона
  - Ввести восьмизначный код авторизации устройства из терминала (*на операцию выделяется 300 секунд!*)
  - Согласится с подключением устройства
  - Вернуться в терминал и задать путь к каталогу Яндекс Диска в Домашнем каталоге пользоватя (*по умолчанию, если оставить ввод пустым, будет создан каталог по адресу `$HOME/Yandex.Disk/`*)
  - Согласиться с запуском Яндекс Диска при входе в систему

**Демон будет запущен как фоновый процесс. Синхронизация данных с облаком будет выполняться через указанный при настройке каталог**

## Индикация состояния работы Яндекс Диска

**Неофициальный пакет от стороннего разработчика!**

- Скачать с портала установочный пакет из Библиотеки приложений: [yandex-disk-indicator.deb](https://easyastra.ru/store1.8/yandex-disk-indicator.deb)
- Двойным кликом ЛКМ выполнить установку пакета средствами qApt
- Запустить единоразово утилиту из **Меню "Пуск" -> Интернет -> Индикатор Yandex.Disk**

*В области уведомлений должен отображаться значек-индикатор работающего приложения. В конекстном меню утилиты доступны различные информационные данные и настройки*
