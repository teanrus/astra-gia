## 1. Общие сведения

**Проверено на:**

- Astra Linux SE 1.8 x86-64
- Репозитории:
  - `https://download.astralinux.ru/astra/stable/1.8_x86-64/repository-main`
  - `https://download.astralinux.ru/astra/stable/1.8_x86-64/repository-extended`

**Используемые инструменты:** `apt`, `tmux`

---

## 2. Важное предупреждение

В Astra Linux **команда `apt upgrade` отключена на уровне конфигурации** и не может быть использована:

```
E: 'apt-get upgrade' отключена, поскольку это может привести систему в нерабочее состояние.
   Вместо этого рекомендуется использовать 'apt-get dist-upgrade'.
```

Это сделано намеренно: `apt upgrade` **не удаляет устаревшие пакеты и не разрешает сложные зависимости**, что в ряде случаев приводит к несовместимости версий и делает систему незагружаемой.

**Правильный способ обновления — `apt dist-upgrade` (он же `apt full-upgrade`).**

## 3. Подготовка к обновлению

### 3.1. Сделайте резервную копию

Перед массовым обновлением (в вашем случае — 1711 пакетов) обязательно:

- Создайте снапшот ВМ **или**
- Сделайте бэкап важных данных и конфигураций **или**
- Убедитесь, что у вас есть точка отката на уровне гипервизора / СХД.

### 3.2. Убедитесь, что вы в свежем терминале

```bash
whoami
# ожидаем: admin (или другой пользователь с sudo)

hostname
# LARM-060-ASTRA-TEST
```

### 3.3. Обновите список пакетов

```bash
sudo apt update -y
```

---

## 4. Порядок обновления

Выполняйте команды **последовательно**:

```bash
# 1. Обновить список пакетов
sudo apt update

# 2. Обновить систему (правильная команда для Astra Linux)
sudo apt dist-upgrade -y

# 3. Удалить пакеты, ставшие ненужными
sudo apt autoremove -y

# 4. Очистить локальный кэш пакетов
sudo apt autoclean
```

> Если на каком-то шаге `dist-upgrade` задаёт вопросы по конфигурационным файлам — **по умолчанию выбирайте сохранение старого конфига** (`keep` / `N`), если у вас нет причин поступить иначе.

### Просмотр списка обновляемых пакетов (до обновления)

```bash
apt list --upgradable
```

## 5. Работа в tmux (рекомендуется для SSH)

Обновление 1700+ пакетов может занять десятки минут. При работе через SSH обрыв связи прервёт процесс. `tmux` решает эту проблему.

```bash
# Установить tmux (если ещё не установлен)
sudo apt install -y tmux

# Создать новую сессию
tmux new -s upgrade

# Внутри tmux запустить обновление
sudo apt dist-upgrade -y

# Отключиться от сессии, не прерывая процесс: Ctrl+B, затем D
# Вернуться к сессии позже:
tmux attach -t upgrade
```

## 6. Действия после обновления

### 6.1. Проверить, требуется ли перезагрузка

Если обновилось ядро (`linux-image-*`) — перезагрузка обязательна:

```bash
# Список установленных ядер
dpkg -l | grep linux-image

# Текущая версия ядра
uname -r

# Если в списке есть более новое ядро — перезагрузитесь
sudo reboot
```

### 6.2. Проверить состояние системы

```bash
# Убедиться, что нет сломанных зависимостей
sudo apt check

# Список оставшихся обновлений (должен быть пустым или минимальным)
apt list --upgradable

# Состояние ключевых сервисов (пример)
systemctl --failed
```

## 7. Частые проблемы и решения

### 7.1. «`apt-get upgrade` отключена»

**Причина:** защитный механизм Astra Linux.
**Решение:** использовать `sudo apt dist-upgrade -y` (см. раздел 4).

Использовать `--enable-upgrade` **не рекомендуется** — это может повредить систему.

### 7.2. Конфликт конфигурационных файлов

При обновлении `apt` может спросить:

```bash
*** default action for /etc/... ***
```

- Хотите сохранить свои настройки → **`keep the local version`** (`N`).
- Хотите принять версию из пакета → `install the package maintainer's version` (`Y`).

### 7.3. Прерванное обновление

Если процесс был прерван (SSH, питание, Ctrl+C):

```bash
sudo dpkg --configure -a
sudo apt --fix-broken install
sudo apt dist-upgrade -y
```

### 7.4. Не хватает места на диске

```bash
# Проверить место
df -h

# Очистить кэш apt
sudo apt clean
sudo apt autoclean
sudo apt autoremove --purge -y
```

### 7.5. Сессия SSH оборвалась во время обновления

- Подключитесь заново.
- Проверьте, не остался ли `apt`/`dpkg` в рабочем состоянии:
  ```bash
  ps aux | grep -E 'apt|dpkg'
  ```
- При необходимости восстановите состояние (см. 7.3).
- **Впредь используйте `tmux`** (раздел 5).

## 8. Краткая шпаргалка

```bash
# Обновление системы Astra Linux 1.8
sudo apt update
sudo apt dist-upgrade -y
sudo apt autoremove -y
sudo apt autoclean

# При необходимости
sudo reboot

# Проверка
apt list --upgradable
systemctl --failed
```

**Запомните:** в Astra Linux **вместо `apt upgrade` всегда используйте `apt dist-upgrade`**.
