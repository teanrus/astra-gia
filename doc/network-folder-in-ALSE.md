# Подключение к сетевой папке в Astra Linux

>Подключение к сетевой папке в Astra Linux можно выполнить двумя основными способами: через графический интерфейс файлового менеджера `fly-fm` или через командную строку.
>Выбор зависит от удобства и того, требуется ли постоянный доступ.

## 🖱️ Способ 1: Через графический интерфейс (Менеджер файлов)

Это самый простой и быстрый способ для разового подключения.

1. **Установите точку подключения**: Сначала создайте локальную папку, куда будет «встроена» сетевая папка. Это можно сделать прямо в менеджере файлов или через терминал: `mkdir ~/Сетевые_Ресурсы`.
2. **Создайте сетевое место**: В менеджере файлов (Менеджер файлов / Fly-FM) в верхнем меню выберите **«Сеть»** → **«Создать сетевое место»**.
3. **Укажите адрес**: В открывшемся окне введите имя (произвольно) и адрес в формате `smb://IP_АДРЕС_СЕРВЕРА/ИМЯ_ПАПКИ`. Например: `smb://192.168.1.17/share`.
4. **Введите учетные данные**: Система запросит логин и пароль пользователя, у которого есть доступ к этой сетевой папке на сервере.

## 💻 Способ 2: Через командную строку (Монтирование)

Этот способ предпочтительнее, если нужно, чтобы папка всегда была доступна в определенной точке или если графический интерфейс недоступен.

**Шаг 1. Установите необходимый пакет**
Для работы с сетевыми папками Windows (SMB/CIFS) нужен пакет `cifs-utils`:

```bash
sudo apt install cifs-utils
```

**Шаг 2. Создайте точку монтирования**
Выберите папку, куда будет смонтирован сетевой ресурс, например `/mnt/share`:

```bash
sudo mkdir -p /mnt/share
```

**Шаг 3. Выполните монтирование**
Используйте команду `mount` с типом файловой системы `cifs`:

```bash
sudo mount -t cifs //АДРЕС_СЕРВЕРА/ИМЯ_ПАПКИ /mnt/share -o username=ВАШ_ЛОГИН,password=ВАШ_ПАРОЛЬ
```

**Пример** с IP-адресом `10.0.10.201` и папкой `share`:
```bash
sudo mount -t cifs //10.0.10.201/share /mnt/share -o username=admin,password=12345
```
Если пароль не указан в опции `password`, система запросит его в интерактивном режиме.

**Шаг 4. Проверка**
Перейдите в папку `cd /mnt/share` и проверьте наличие файлов командой `ls`.

```bash
sudo mount -t cifs //10.0.10.201/share /mnt/share -o username=admin,password=12345,vers=1.0
```

## Для постоянного монтирования при загрузке системы нужно добавить соответствующую запись в файл `/etc/fstab`.

Постоянное монтирование в `/etc/fstab` имеет смысл, если вы хотите, чтобы сетевая папка подключалась автоматически при каждой загрузке системы. Чтобы не хранить пароль в открытом виде и не рисковать блокировкой загрузки, делайте это правильно.

### 🔐 Шаг 1: Создайте файл с учетными данными

Пароль лучше не писать прямо в `/etc/fstab` — этот файл доступен всем на чтение. Создайте отдельный файл с правами доступа только для root .

```bash
sudo install -d -m 700 /etc/samba
sudo nano /etc/samba/credentials-share
```

Введите в файл строки с вашими данными:

```bash
username=ВАШ_ЛОГИН
password=ВАШ_ПАРОЛЬ
domain=WORKGROUP
```

Сохраните и установите строгие права:

```bash
sudo chmod 600 /etc/samba/credentials-share
sudo chown root:root /etc/samba/credentials-share
```

### 📝 Шаг 2: Добавьте запись в `/etc/fstab`

Откройте файл на редактирование:

```bash
sudo nano /etc/fstab
```

Добавьте в конец строку в таком формате:

```bash
//IP_СЕРВЕРА/ИМЯ_ПАПКИ  /mnt/share  cifs  credentials=/etc/samba/credentials-share,uid=1000,gid=1000,file_mode=0664,dir_mode=0775,_netdev,nofail  0  0
```

**Важные опции** :
- `uid=1000,gid=1000` — укажите ваш реальный UID и GID (посмотрите командой `id`), чтобы файлы не принадлежали root
- `_netdev` — критично важно. Указывает, что монтирование возможно только после поднятия сети. Без этой опции система может зависнуть при загрузке
- `nofail` — система продолжит загрузку, даже если сервер недоступен
- `vers=3.0` — если сервер старый или выдает ошибку, укажите версию протокола (2.0, 3.0 или 1.0 для особых случаев в Astra Linux)

### ✅ Шаг 3: Проверка

Проверьте конфигурацию без перезагрузки:

```bash
sudo mount -a
```

Если ошибок нет, перезагрузитесь или вручную отмонтируйте и смонтируйте снова:

```bash
sudo umount /mnt/share && sudo mount /mnt/share
```

## ⚠️ Важное замечание для Astra Linux Special Edition

Если вы используете **Astra Linux Special Edition (режим «Смоленск»)** с включенным мандатным контролем доступа (МКЦ), учтите нюанс: при монтировании CIFS-ресурсов, содержащих конфиденциальные данные, **допустимо использовать только версию протокола SMB 1.0 (NT1)**. В этом случае команда монтирования должна содержать опцию `vers=1.0`
