# Язык «1С:Элемент»

***

> Язык «1С:Элемент» — это кросс-платформенный язык программирования высокого уровня со статической типизацией, стандартной библиотекой и поддержкой функционального программирования. Используется для создания программ, обработки данных, автоматизации различных процессов и решения задач любой сложности

## Установка инструментов разработки

- Перейдите на [официальный сайт](https://lang.1c.ru)
- Нажмите кнопку "Скачать дитрибутив"
- Выберите `Дистрибутив для Linux` (*Архив с установщиком в формате .tar.gz*)
- Распакуйте скачанный архив и перейдите в каталог
- Двойным кликом ЛКМ запустите исполняемый файл `1ce-installer`
- Следуйте пошагово инструкциям устанощика на экране
- После заверешния установки софт доступен в **Меню "Пуск" -> Разработка -> 1C-Enterprise-Element-Script**
- Запустите среду и создайте `Новый скрипт`

> В качестве альтернативы можно использовать ту же самую среду, но в виде онлайн сервиса: [Среда разработки](https://1cmycloud.com/console/play)

## Запуск скрипта

- Напишите необходимый скрипт

```bash
метод Скрипт()
    Консоль.Записать("Привет, Мир!")
;
```

- Нажмите кнопку запустить над объявлением реализованного метода
- Скрипт будет исполнен во встроенном терминале среды разработки
