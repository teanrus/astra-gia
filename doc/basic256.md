# Инструменты разработки на языке Basic

***

> **Basic 256** - это простой диалект языка BASIC и одновременно интегрированная среда разработки (IDE), созданная специально для обучения программированию (в первую очередь школьников)

## Установка и запуск среды

- Среда может быть установлена из штатного репозитория ОС
- Запустите терминал: `Alt+T`
- Установите пакет, выполнив: `sudo apt -y install basic256`
- Авторизуйтесь с правами пользователя `root` и дождитесь завершения установки
- Более свежую версию пакета можно скачать на портале: [basic256.deb](https://easyastra.ru/store1.8/basic256.deb)
- Среда будет доступна для запуска из **Меню "Пуск" -> Научные**

### Пример простой программы

- Наберите листинг программы

```basic
INPUT "Введите первое число: ", a
INPUT "Введите второе число: ", b

PRINT "Сумма: "; a + b

END
```

- Запустите исполнение, нажав на панели инструментов кноку **Старт** или клавишу `F5`
