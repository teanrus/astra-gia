# Подключение сетевых интернет репозиториев, обновление ОС и пакетная установка дополнительного программного обеспечения

***

## Сетевые интернет репозитории

> [Интернет-репозитории Astra Linux](https://wiki.astralinux.ru/pages/viewpage.action?pageId=302043111) предназначены для обеспечения процедуры обновления ОС при наличии доступа в Интернет и позволяют выполнять установку и обновление пакетов с помощью стандартных установщиков пакетов:  [графический менеджер пакетов synaptic](https://wiki.astralinux.ru/pages/viewpage.action?pageId=27362363) и инструмент командной строки apt

### Подключение репозиториев через утилиту портала Repo Update Checker

> Утилита написана для максимально простого способо активации stable/frozen репозиториев и установки обновления пакетов правильным способом

- Загрузите с портала пакет: [repo-update-checker.deb](https://easyastra.ru/utils/repo-update-checker.deb)
- Запустите установку пакета двойным кликом ЛКМ 
- После завершения установки запустите приложения с ярлыка **Активация репозиториев** на Рабочем столе
- Авторизуйтесь с правами `root` пользователя
- Выберите ветку `stable` или `frozen` и нажмите кнопку **Активировать и обновить список пакетов**
- При выборе ветки `stable` после активации репозиториев нажмите кноку **Проверить и установить обновления ОС**
- Дождитесь завершения операций

### Подключение репозиториев через Synaptic

> Нерекомендуемый способ!!!

- Найдите и запустите через Меню "Пуск" `Менеджер пакетов Synaptic`
- Авторизуйтесь с правами `root` пользователя
- Перейдите в главном меню в раздел **Настройки -> Репозитории**
- Снимите галочку с репозитория установочного диска вида `deb cdrom: ...`
- Отметьте галочками два репозитрия: `repository-main` и `repository-extended`
- Нажмите кнопку **ОК** и **Обновить**

> Не используйте `Менеджер пакетов Synaptic` как инструмент обновления пакетной базы!!!

### Подключение репозиториев через ФС

- Запустите файловый менеджер
- Перейдите в Место **Файловая система**
- Перейдите по адресу `/etc/apt/`
- Двойным кликом ЛКМ откройте на редактирование файл `sources.list`
- Установите знак `#` для записи о репозитории установочного диска вида `deb cdrom: ...`
- Удалите знак `#` в записях для репозиториев `repository-main` и `repository-extended`
- Нажмите кнопку **Сохранить** на панели инструментов редактора
- Авторизуйтесь с правами `root` пользователя
- Закройте текстовый редактор Kate
- Запустите Терминал: `Alt+T`
- Обновите список пакетов: `sudo apt update`

### Подключение репозиториев через CLI

- Запустите Терминал: `Alt+T`
- Откройте на редактирование файл со списком репозиториев: `sudo nano /etc/apt/sources.list`
- Авторизуйтесь с правами `root` пользователя
- Установите знак `#` для записи о репозитории установочного диска вида `deb cdrom: ...`
- Удалите знак `#` в записях для репозиториев `repository-main` и `repository-extended`
- Сохраните внесенные изменения: `Ctrl+O` и подтвердите клавишей ВВОД (Enter)
- Закройте текстовый редактор `nano` выполнив `Ctrl+X`
- Обновите список пакетов: `sudo apt update`

> Список актуальных сетевых интернет репозиториев ветки stable:

```bash
    deb https://dl.astralinux.ru/astra/stable/1.8_x86-64/main-repository/ 1.8_x86-64 main contrib non-free non-free-firmware
    deb https://dl.astralinux.ru/astra/stable/1.8_x86-64/extended-repository/ 1.8_x86-64 main contrib non-free non-free-firmware
```

> Astra Linux SE 1.8 позволяет подключать и использовать репозитории `Debian 12 Bookworm`, подробнее [тут](https://wiki.astralinux.ru/pages/viewpage.action?pageId=3276859)

## Обновление пакетной базы ОС

> Убедитесь в активности сетевых интернет репозиториев и доступе к сети Интернет

### Графический режим и утилита fly-astra-update

- Найдите и запустите через Меню "Пуск" `Установка обновлений`
- Авторизуйтесь с правами `root` пользователя
- Нажмите кнопку **Экспертный режим**
- Снимите галочку **Автоматическое обновление приложения**
- Установите галочки **Установка обновления из репозиториев /etc/apt/sources.list** и **Не искать репозиторий установочного диска**
- Нажмите кнопку **Обновить**

> Не используйте `Менеджер пакетов Synaptic` как инструмент обновления пакетной базы!!!

### Терминальный режим и утилита astra-update

- Запустите Терминал: `Alt+T`
- Введите команду: `sudo astra-update -A -r -T`
- Нажмите ВВОД (Enter) и авторизуйтесь с правами `root` пользователя

## Установка программного обеспечения

### Установка из репозиториев ОС

#### Через Менеджер пакетов Synaptic

- Найдите и запустите через Меню "Пуск" `Менеджер пакетов Synaptic`
- Авторизуйтесь с правами `root` пользователя
- Через поиск найдите необходимый пакет, например `yandex-browser`
- Вызовите контекстное меню через ПКМ на найденом пакете и выберите `Отметить для установки` и **Применить**
- Нажмите на панели инструментов **Применить** и еще раз **Применить** в открывшемся диалоговом окне
- Закройте окно установки после завершения операций

#### Через Терминал в режиме CLI

- Запустите Терминал: `Alt+T`
- Обновите список доступных пакетов: `sudo apt update`
- Установите необходимый пакет, выполнив `sudo apt -y install package`, где package = имя устанавливаемого пакета
- Авторизуйтесь с правами `root` пользователя
- Дождитесь завершения операций

### Установка сторонних .deb пакетов

#### В графическом режиме средствами qApt

- Загрузите необходимый пакет, например из [Библиотеки приложений](https://easyastra.ru/resources/store1.8.php)
- Перейдите в каталог загрузки пакета средствами Файлового менеджера
- Двойным кликом ЛКМ запустите скачанный пакет на установку
- Нажмите **Установить пакет**
- Авторизуйтесь с правами `root` пользователя
- Дождитесь завершения операций и нажмите **Применить**

#### В режиме CLI средствами apt

- Загрузите необходимый пакет, например из [Библиотеки приложений](https://easyastra.ru/resources/store1.8.php)
- Перейдите в каталог загрузки пакета средствами Файлового менеджера
- Вызовите через **ПКМ Контекстное меню -> Открыть терминал в этой папке** или из главного меню Файлового менеджера **Сервис -> Открыть терминал**
- Выполните команду для установки: `sudo apt -y install ./package.deb`, где package.deb = имя вашего пакета
- Авторизуйтесь с правами `root` пользователя
- Дождитесь завершения операций

## Удаление ранее установленных пакетов

- Найдите установленный пакет средствами `Менеджера пакетов Synaptic` и отметьте на удаление
- Выполните в терминале команду `sudo apt -y remove package`, где package = имя вашего пакета
