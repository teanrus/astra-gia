# Установка и настройка dotnet для работы с `C#`

***

*В репозитории ОС доступны 8-я и 10-я версии SDK dotnet*

> Перед установкой ПО убедитесь в подключении сетевых интернет репозиториев ОС и доступности сети Интернет

## Установка пакетов .Net Core

- Откройте териминал Fly: `Alt+T`
- Обновите базу с информацией о пакетах: `sudo apt update`
- Установите инструменты разработки: `sudo apt -y install dotnet-sdk-10.0` (*или 8.0 в зависимости от версии дистрибутива*)

## Редактор Visual Studio Code

*Рекомендуемая среде разработки (IDE) для Astra Linux Special Edition 1.8*

- Скачайте с портала из Библиотеки приложений пакет: [code.deb](https://easyastra.ru/store1.8/code.deb)
- Запустите его установку двойным кликом ЛКМ средствами утилиты qApt
- Запустите редактор из **Меню "Пуск" -> Разработка -> Visual Studio Code**
- Перейдите в разде расширений (левая панель Меню) и установите расширение, найдя в поиске, для C# - **C# Dev Kit от Microsoft**
- При необходимости доустановите расширение поддержки русской локализации интерфейса программы - **Russian Languge Pack for Visual Studio Code от Microsoft**

> [Установка расширений в VS Code самостоятельно без Менеджера плагинов](vscode-extentions-manual.md)

### Создание простого проекта на C# в VS Code

- Запустите редактор Visual Studio Code
- Откройте терминал: **Меню -> Файл -> Создать файл**
- Укажите `.NET: создать файл... Комплект разработки С#`
- Будет выполнен поиск шаблонов проектов, укажите `Консольное приложение`
- Укажите директорию создания проекта и нажмите кнопку `Открыть`
- Укажите желаемое имя нового создаваемого проекта и подтвердите, нажав **ВВОД (ENTER)**
- Выберите мышкой `+ Создать проект`
- Напишите необходимый код проекта в файле `Program.cs` (*по дефолту уже есть простой Hello, World!*)

```bash
    Console.WriteLine("Hello, World!");
```

- Сохраните изменения в файле Program.cs: **Меню -> Файл -> Сохранить**
- Нажмите "Запустить проект" (**кнопка play на панели**) и дождитесь запуска программы во встроенном терминале среды разработки

## Создание проекта с использованием консоли и редактора Kate

> Редактор Kate установлен в ОС по умолчанию. В случае отсутсвия может быть установлен из репозитория: `sudo apt -y install kate`

- Откройте териминал Fly: `Alt+T`
- Создайте каталог проекта в Домашнем каталоге пользователя, например: `mkdir NET/`
- Перейдите во вновь созданный каталог: `cd NET/`
- Создайте в каталоге новый консольный проект, выполнив в терминале `dotnet new console`
- По дефолту в каталоге с проектом будет создан файл `Proram.cs` простой программой вида *Hello, World!*
- Средствами ФМ перейдите в каталог с проектом и откройте файл `Proram.cs` в редакторе **Kate** или выполните команду `kate Program.cs` для быстрого открытия файла в редакторе
- Внесите и сохраните изменения в файле `Program.cs` средствами редактора **Kate**
- Для запуска проекта вернитесь в терминал и в каталоге с проектом выполните команду `dotnet run`

> [Видео пример работы с терминалом и редактором Kate](https://easyastra.ru/resources/EGE/media/csharp-dotnet.mp4)

#### Приведение программы к виду ProgramMain в VS Code

> В ходе работы над консольным проектом «загорается лампочка подсказка» при нажатии на которую редактор предлагает автоматически привести проект к стилю использования классов! Это касается и дефолтной простой программы на языке C#

```bash
using System;

namespace HelloWorldApp {
    class Program {
        static void Main(string args) {
            Console.WriteLine("Hello, World!");
        }
    }
}
```

### Альтернативные решения

> **CrutchSharp** - маленькая графическая утилита для создания, редактирования и запуска консольных приложений на DotNet C#

- Скачайте и установите пакет с портала: [Скачать](https://easyastra.ru/utils/crutchsharp.deb)
- Запустите из Меню "Пуск" -> Разработка

*Приложение позволяет автоматизировать процесс создания консольного приложения на C#, вызывать на редактировние штатный редактор Kate и запускать написанную программу в штатном терминале ОС*

> **MonoDevelop** - интегрированная среда разработки (IDE) с открытым исходным кодом. Среда поддерживает C#, F#, Visual Basic .NET

- Скачайте и установите пакет с портала: [Скачать](https://easyastra.ru/store1.8/monodevelop.deb)
- Запустите из Меню "Пуск" -> Разработка
- Создайте новый проект: **Создать -> .NET -> Консольный проект (C#)**
- Укажите желаемое имя проекта и нажмите кнопку "Создать"
- Запустите программу через меню "Запуск" или с Панели инструментов

> **Geany** - лёгкий кроссплатформенный текстовый редактор с открытым исходным кодом. Среда не предназначена для полноценной работы с C# dotnet, но позволяет настроить сборку и исполнение программы в графическом интерфейсе

- Установите инструменты разработки: `sudo apt -y install dotnet-sdk-10.0`
- Редактор может быть установлен из репозитория ОС: `sudo apt -y install geany geany-plugins`
- Более свежая версия доступна на портале: [Скачать](https://easyastra.ru/store1.8/geany.deb)
- Запустите редактор, создайте пустой файл и сохраните под любым именем с расширением файла `.cs`
- Настройте правила сборки и запуска программы:
  - Вызовите в главном меню редактора **Сборка -> Установить команды сборки**
  - Для метки `Скомпилировать` укажите параметр `dotnet "%f"`
  - Для метки `Собрать` укажите параметр `dotnet publish "%f"`
  - Для метки `Выполнить` укажите параметр `artifacts/"%e"/"%e"`
  - Сохраните внесенные изменения
- Напишите простой листинг, например
  
```bash
    Console.WriteLine("Hello, World!");
```

- Для запуска программы и вывода результата во встроенный терминал нажмите `F8` или значек `Скомпилировать текущий файл` на панели инструментов
- Для получения бинарного файла программы и вызова его во внешнем терминале ОС выполните:
  - Соберите проект, нажав `Shift+F9` - в подкаталоге `artifacts/` каталога с проектом будет собран бинарный файл программы
  - Запутите собранный ранее бинарный файл, нажав `F5`
