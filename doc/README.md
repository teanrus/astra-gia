# Документация проекта Astra GIA

Этот каталог содержит технические материалы, относящиеся к подготовке и настройке рабочих мест на Astra Linux под проведение ГИА.

## Содержимое

### disk-layout.md

Описание рекомендуемой схемы разметки диска для Astra Linux 1.8. Документ включает:

- таблицу разделов;
- назначение точек монтирования `/`, `/var`, `/tmp`, `/home`, `/boot`, `/boot/efi`;
- рекомендации по размерам разделов;
- пояснение, почему такая схема считается оптимальной для экзаменационных рабочих мест.

## Когда использовать

- при установке Astra Linux с нуля;
- при подготовке рабочих станций для экзаменационного пункта;
- при проектировании надежной и безопасной файловой структуры для систем с высокой нагрузкой.

## Ключевая идея

Схема разделения диска направлена на:

- защиту данных пользователя;
- снижение риска переполнения системных каталогов;
- облегчение обслуживания и восстановления;
- резервирование пространства под логи, временные файлы и swap.
