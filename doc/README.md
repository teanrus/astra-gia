# Документация проекта Astra GIA

Этот каталог содержит инструкции по подготовке рабочих мест на Astra Linux к проведению ГИА: настройке системы и сети, установке программ, языкам программирования и учебным приложениям.

## Содержимое

### Подготовка и обслуживание системы

- [Разметка диска](disk-layout.md) — рекомендуемые разделы и точки монтирования для Astra Linux.
- [Репозитории и обновление ОС](repo-update-install.md) — подключение репозиториев, обновление системы и установка программ.
- [Подключение к сети через ЕСПД](espd.md) — настройка доступа к интернету через ЕСПД.

### Языки программирования и учебные среды

- [1С:Элемент](1c-element-language.md) — язык и среда разработки 1С:Элемент.
- [Basic 256](basic256.md) — учебная среда для программирования на BASIC.
- [C и C++ в VS Code](c-cpp-vscode.md) — настройка компилятора и среды разработки.
- [C# и .NET](dotnet-csharp.md) — установка и настройка .NET для C#.
- [Java](java.md) — инструменты и среды разработки Java.
- [КуМир 2](kumir2.md) — алгоритмическая среда для обучения программированию.
- [Pascal](pascal.md) — инструменты разработки на Pascal.
- [Python в VS Code](python.md) — настройка среды разработки и запуска Python.

### Приложения и дополнительные настройки

- [КриптоПро и порталы Госуслуг](cryptopro-gos.md) — установка КриптоПро и плагинов для работы с государственными порталами.
- [LibreOffice Base](libreoffice-base.md) — настройка LibreOffice Base для работы со встроенной базой данных.
- [Установка расширений VS Code вручную](vscode-extentions-manual.md) — установка расширений без менеджера плагинов.
- [Яндекс Диск](yandex-disk.md) — установка и настройка десктопного клиента.

## Когда использовать

- при установке и обновлении Astra Linux;
- при настройке сети и подготовке рабочих станций для экзаменационного пункта;
- при установке учебного и прикладного программного обеспечения.

## Ключевая идея

Материалы помогают подготовить систему, выбрать и настроить нужные инструменты, а также упростить дальнейшее обслуживание рабочих мест.
