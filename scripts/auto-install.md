# 🎓 Автоматизация установки ПО для ГИА на Astra Linux SE 1.8

Интерактивный bash-скрипт для быстрого и автоматизированного развертывания программного обеспечения, необходимого для проведения Государственной Итоговой Аттестации (ЕГЭ, ОГЭ по информатике и другим предметам) в операционной системе **Astra Linux Special Edition 1.8**.

Скрипт позволяет гибко выбрать необходимый набор программ из интерактивного меню, избегая установки лишнего софта на рабочие места экзаменуемых.

## ⚙️ Требования

- **ОС:** - Astra Linux Special Edition 1.8 (x86_64).
- **Права:** - Пользователь с правами `sudo` (или root).
- **Сеть:** - Наличие доступа в интернет для скачивания пакетов с `easyastra.ru` и `gitflic.ru`.
- **Базовые утилиты:** - `wget`, `curl`, `apt`, `gpg` (обычно предустановлены в ALSE).

## 🚀 Установка и запуск

### 1. Скачивание скрипта

Вы можете клонировать репозиторий или скачать скрипт напрямую:

```bash
# Клонирование репозитория
git clone https://gitflic.ru/project/ваш_репозиторий/astra-gia-installer.git
cd astra-gia-installer

# ИЛИ скачивание только скрипта
wget https://gitflic.ru/project/ваш_репозиторий/astra-gia-installer/blob/raw?file=auto-install.sh -O auto-install.sh
```

### 2. Запуск

Сделайте скрипт исполняемым и запустите его:
```bash
chmod +x auto-install.sh
./auto-install.sh
```

>Примечание: Скрипт сам запросит права sudo в процессе работы для установки пакетов и настройки репозиториев.

### 3. Работа с меню

- Нажмите Enter для начала опроса.
- Отвечайте y (или д) для установки и n (или н) для пропуска.
- Для пакетов R7 Office и MAX скрипт предложит выбор: скачать готовый .deb или подключить официальный репозиторий (рекомендуется для упрощения будущих обновлений).
- Выберите нужную версию Python из списка.
- Дождитесь завершения скачивания, установки и очистки временных файлов.

## 🛠 Как это работает (под капотом)

- Обновление кэша: Скрипт выполняет sudo apt update.
- Сборка очереди: На основе ваших ответов формируются массивы URL-адресов и имен пакетов.
- Скачивание .deb: Создается временная директория tmp_deb/, куда через wget скачиваются выбранные пакеты.
- Установка: Выполняется sudo apt -y install ./*.deb (используется apt вместо dpkg для автоматического разрешения зависимостей).
- Настройка репозиториев: Если выбрано, скрипт автоматически добавляет GPG-ключи и sources.list для R7 Office и MAX.
- Очистка: Временная папка tmp_deb/ удаляется после завершения.
  
>⚠️ Важные примечания
>Сетевые ограничения: Если на компьютерах в экзаменационном пункте стоит строгий фаервол/прокси, убедитесь, что разрешены подключения к easyastra.ru, gitflic.ru, downloads.r7-office.ru и download.max.ru.
>Версии Python: Представленные пакеты Python (3.9 - 3.14) собраны специально для совместимости с ALSE 1.8 и тестировались в средах проведения экзаменов.
>Повторный запуск: Скрипт можно запускать многократно. Если пакет уже установлен, apt просто пропустит его или обновит, если доступна новая версия.
