# Установка расширений VS Code из релиза Astra GIA

Скрипт автоматически скачивает архив с расширениями из релиза проекта Astra GIA и распаковывает его в каталог `~/.vscode/` текущего пользователя.

Это удобно в ситуациях, когда стандартный способ установки расширений в VS Code недоступен или заблокирован, а администраторам нужно быстро развернуть нужный набор расширений для подготовки к ГИА.

## Что делает скрипт

1. Загружает архив `extensions.tar.gz` из релиза GitHub.
2. Проверяет, что в архиве есть каталог `extensions/`.
3. Создает каталог `~/.vscode/` при необходимости.
4. Копирует содержимое каталога `extensions/` в `~/.vscode/` с сохранением структуры.
5. Позволяет выполнять проверку без реального скачивания и распаковки через флаг `--dry-run`.

## Требования

- Установленный `curl`.
- Установленный пакет VS Code (`code.deb`) из релиза Astra GIA.
- Сессия целевого пользователя должна быть создана и запущена один раз, чтобы VS Code создал стандартные настройки и каталог `~/.vscode/`.

## Сценарий использования

### 1. Установка для текущего пользователя

```bash
./install-vscode-extensions.sh
```

### 2. Установка для конкретного пользователя

```bash
./install-vscode-extensions.sh --home /home/student
```

### 3. Только показать список пользователей

```bash
./install-vscode-extensions.sh --list-users
```

Скрипт выведет список пользователей из `/home/*` и завершится без установки.

### 4. Выбор пользователя из списка

```bash
./install-vscode-extensions.sh --select-user
```

После запуска скрипт прочитает список пользователей из `/home/*`, покажет их в виде нумерованного списка и попросит выбрать нужного.

### 5. Автоматический выбор первого найденного профиля

```bash
./install-vscode-extensions.sh --auto
```

Скрипт сам выберет первый найденный профиль из `/home/*` и продолжит установку для него.

### 6. Установка для конкретного пользователя по имени

```bash
./install-vscode-extensions.sh --user student
```

### 7. Проверка без изменения системы

```bash
./install-vscode-extensions.sh --dry-run
```

### 8. Использование другого тега релиза

```bash
./install-vscode-extensions.sh --release v2.0
```

## Как это связано с подготовкой рабочих мест

Рекомендуемый порядок действий для администратора:

1. Установить пакет среды VS Code из релиза: `code.deb`.
2. Запустить VS Code один раз в сессии целевого пользователя и закрыть его.
3. Запустить этот скрипт.
4. Проверить, что расширения появились в каталоге `~/.vscode/`.

После этого при следующем запуске VS Code для этого пользователя расширения будут доступны и готовы к работе.

## Примечания

- Скрипт сохраняет содержимое каталога `extensions/` в `~/.vscode/`.
- Если в целевом каталоге уже есть файлы, они будут перезаписаны новым содержимым.
- Для работы из-под другого пользователя можно использовать `--user`, `--select-user`, `--list-users`, `--auto` или явно указать `--home`.
- При выборе пользователя из списка или автоматическом режиме скрипт берёт директории из `/home/*` и проверяет их в порядке сортировки.
- Режим `--list-users` особенно полезен при массовом развёртывании, когда администратор сначала хочет быстро определить все профили пользователей.
