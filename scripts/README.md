# Скрипты проекта Astra GIA

Этот каталог содержит сценарии автоматизации и вспомогательные инструкции по подготовке рабочих мест для экзаменов в Astra Linux.

## Содержимое

### auto-install.sh

Основной сценарий автоматической установки программного обеспечения для ГИА.

Что умеет:

- выбор ветки репозитория Astra Linux (`frozen` / `stable`);
- подготовку системы к установке стороннего ПО;
- интерактивный режим установки;
- CLI-режим через флаги вроде `--office`, `--internet`, `--programming`, `--graphics`, `--edu`, `--all`;
- режимы `--full-os`, `--browsers-only`, `--education-only`;
- проверку `--dry-run`;
- просмотр списка пакетов `--list`.

Подробности: [auto-install.md](./auto-install.md)

### install-vscode-extensions.sh

Скрипт для автоматической загрузки архива с расширениями VS Code из GitHub Releases и копирования их в `~/.vscode/`.

Что умеет:

- скачивать `extensions.tar.gz` из релиза проекта;
- распаковывать архив;
- копировать содержимое в домашний каталог пользователя;
- выбирать пользователя из списка `/home/*`;
- использовать режимы `--select-user`, `--list-users`, `--auto`, `--dry-run`.

Подробности: [install-vscode-extensions.md](./install-vscode-extensions.md)

### repository-activation.sh

Скрипт для активации репозиториев Astra Linux 1.8 и подготовки среды к установке стороннего программного обеспечения и зависимостей.

## Рекомендуемый порядок работы

1. Выполнить активацию репозиториев, если это необходимо.
2. Запустить основной скрипт `auto-install.sh` для настройки нужного набора ПО.
3. При необходимости установить расширения VS Code через `install-vscode-extensions.sh`.
4. Проверить итоговое состояние рабочего места и при необходимости повторить установку для других пользователей.

## Быстрый старт

```bash
cd scripts
./auto-install.sh
./install-vscode-extensions.sh --select-user
```
