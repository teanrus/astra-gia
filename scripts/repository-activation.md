# Описание работы скрипта `repository-activation.sh`

## Назначение

Скрипт автоматизирует настройку репозиториев APT в операционной системе **Astra Linux Special Edition (ALSE) 1.8**. Предназначен для подключения официальных репозиториев Astra Linux с целью установки стороннего программного обеспечения и зависимостей.

## Область применения

Актуален для:
- АРМ ГИА-11 в ППЭ (при выборе ветки Frozen);
- рабочих станций и серверов под управлением ALSE 1.8, требующих доступа к расширенному набору пакетов.

## Принцип работы

1. Скрипт выводит в терминал информационное меню с двумя вариантами настройки репозиториев.
2. Пользователю предлагается ввести числовое значение (`1` или `2`) для выбора ветки репозитория.
3. В зависимости от введённого значения выполняются следующие действия:

### Вариант 1 — Ветка Frozen (для ALSE 1.8.4.48)

Рекомендуется для АРМ ГИА-11 в ППЭ.

- Полностью перезаписывает файл `/etc/apt/sources.list`, подключая репозитории:
  - `repository-extended` (расширенный);
  - `repository-main` (основной).
- Адрес: `https://download.astralinux.ru/astra/frozen/1.8_x86-64/1.8.4/`
- Архитектура: `amd64`
- Компоненты: `main contrib non-free non-free-firmware`
- После записи выполняется `sudo apt update`.

### Вариант 2 — Ветка Stable (для ALSE 1.8)

Обеспечивает получение оперативных обновлений ОС.

- Полностью перезаписывает файл `/etc/apt/sources.list`, подключая репозитории:
  - `repository-extended` (расширенный);
  - `repository-main` (основной).
- Адрес: `https://download.astralinux.ru/astra/stable/1.8_x86-64/`
- Архитектура: `amd64`
- Компоненты: `main contrib non-free non-free-firmware`
- После записи выполняется `sudo apt update`.

### Некорректный ввод

Если введено значение, отличное от `1` или `2`, выводится сообщение «Действие отсутствует...», и скрипт завершается без изменений в системе.

## Требования

- ОС: Astra Linux Special Edition 1.8 (x86-64).
- Права: пользователь должен иметь возможность выполнять команды через `sudo`.
- Наличие доступа в интернет к ресурсу `download.astralinux.ru`.
- Установленный пакет `apt`.

## Использование

```bash
chmod +x repository-activation.sh
./repository-activation.sh
```

Далее ввести `1` или `2` и нажать Enter.

## Важные замечания

- Скрипт **полностью перезаписывает** файл `/etc/apt/sources.list`. Если в нём были другие записи, они будут утеряны. Рекомендуется предварительно сделать резервную копию:
  ```bash
  sudo cp /etc/apt/sources.list /etc/apt/sources.list.bak
  ```
- Для применения изменений требуется подключение к интернету и корректно настроенные DNS/прокси.
- После успешного выполнения скрипт предлагает закрыть терминал.
- Скрипт завершает работу с кодом `0` в любом случае.
